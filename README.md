# Songloft MIoT Folder View

由 [@Alex1998-my](https://github.com/Alex1998-my) 维护的 Songloft 智能音箱插件社区定制版：把歌单下拉框改成可展开的文件夹列表，方便直接通过小爱音箱点歌。

基于 [songloft-org/songloft-plugin-miot](https://github.com/songloft-org/songloft-plugin-miot) `v2026.10.25.1`。本仓库是衍生修改版，与小米和原项目不存在官方隶属或背书关系。原作者署名及许可证予以保留；本仓库维护者负责这里的定制修改。

## 功能

- 直接列出按文件夹生成的歌单，可同时展开多个列表。
- 展开后直接点歌，或播放整个文件夹。
- 搜索文件夹名称、收起全部。
- 保留原版歌单视图、设备选择、播放控制及设置入口。
- 每个文件夹先显示 100 首，可继续加载显示，避免大量歌曲同时渲染。

这里使用的是 Songloft 的歌单名称，不会重新读取 NAS 目录树；手动创建的歌单也会出现。播放队列仍以所选歌单为单位，并非跨全部文件夹连续播放。

## 安装

适配起点：Songloft v2.13.6 / 官方 MIoT 插件 v2026.10.25.1。

1. 保留现有插件及其配置，不要先卸载。更新前建议备份 Songloft 数据目录。
2. macOS 下载并运行 `dist/install-folder-view.command`；需要系统已安装 Python 3（此工具使用 `/usr/bin/python3`）。
3. 输入自己的 Songloft 地址、Songloft 用户名和密码。输入的是 Songloft 账号，不是小米账号。凭据只用于本次连接，不写入文件。
4. 确认工具显示服务器插件版本 `2026.10.26.2` 后，强制刷新 Songloft 页面。

也可以使用 Songloft 的插件上传功能导入 `dist/miot-folder-view.jsplugin.zip`。部分网页客户端上传存在兼容问题，可使用随附工具。

修改版沿用插件标识 `miot`，属于覆盖更新，不会新增一个独立设备控制实例。工具使用你输入的地址，不含作者家庭 NAS 地址或账号。通过 HTTP 连接时凭据不加密传输，请在可信局域网使用，或配置 HTTPS。

## 构建与来源

```sh
python3 tools/build.py
```

只需 Python 3 标准库。`src/` 保存本仓库新增界面源码；`vendor/` 保存固定版本的上游发行包，`UPSTREAM.json` 记录来源、提交及原包 SHA-256。构建脚本在保留上游后端字节码的情况下替换前端主视图，并按上游规范重新计算 `entryHash` 和 `zipHash`。

这是对固定发行包的最小界面补丁，并非上游整个项目的源码镜像。上游完整源码见其仓库和 `UPSTREAM.json` 中的提交。由于上游前端压缩变量名可能变化，升级上游时需要重新适配与验证。

## 回退与更新

页面内可切换“原版歌单视图”。完整回退可重新上传官方 `v2026.10.25.1` 发行包。修改版没有配置官方自动更新地址，避免被官方发行版直接覆盖；手动升级官方版本会恢复官方界面。
